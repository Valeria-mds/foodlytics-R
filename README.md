# Foodlytics R Shiny Dashboard

## Purpose

Foodlytics is an interactive R Shiny dashboard that helps users to visualizes restaurant quality and type across Canada’s main cities, including cuisine categories and price ranges. It is aimed at businesses and entrepreneurs planning to open a new restaurant. The app helps users understand the local restaurant landscape so they can make better decisions about where to open and what type of restaurant to offer.

The goal is to provide insights that can help businesses decide where and what type of restaurant to open.

## Installation

Clone the repository:

```bash
git clone https://github.com/Valeria-mds/foodlytics-R.git
cd foodlytics-R
```

From Terminal from the root of the repository install the packages by restoring the environment, from **R base**:

```bash
renv::restore()
```

Then to run the application locally:

```bash
shiny::runApp()
```
